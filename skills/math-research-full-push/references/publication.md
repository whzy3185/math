# Publication / referee mode

Use once a real manuscript exists. Keep theorem strength separate from manuscript maturity.

Contribution hierarchy: C1 structural/inverse theorem; C2 global classification; C3 exact endpoint/corollary. Write around the strongest stable mathematics, not discovery chronology.

For each meaningful version: read as a skeptical target-journal referee → record simulated verdict → convert correctness/novelty/boundary/black-box/completeness objections into explicit math obligations → repair or strengthen → regenerate manuscript → re-audit. Never present simulated review as actual peer review.

Default response to a mathematical objection: do not defend weak mathematics; upgrade it. Replace black-box computation with finite reduction, exact endpoint/decision principles, explicit finite propositions and coverage equality where possible.

Freeze only when no correctness blocker remains, strengthening has reached diminishing returns or a recorded obstruction, literature framing is current, proof-critical computation has adequate CAP maturity, paper/Lean/supplement claims align, and the rendered paper has been inspected. Reopen for real error, prior-art collision, meaningful theorem upgrade, or genuine referee/editor request.
