# Theorem-strengthening mode

After the first correct theorem, probe several axes rather than freezing immediately:

- scope: special case → family → broad class → classification;
- hypotheses: remove convenience assumptions;
- quantitative: sharpen constants/exponents and test optimality;
- structure: equality/extremizers/obstructions;
- logic: sufficient → iff;
- algorithmic: exact decision/certificate;
- stability: near-extremal structure;
- unification: one mechanism covering multiple cases.

Falsify stronger variants first and run a targeted prior-art check on any material upgrade.

Use rough strength labels only as summaries: L0 observed, L1 finite verified, L2 mechanism, L3 restricted theorem, L4 broad classification, L5 sharp/equality/iff/stability, L6 unifying framework.

Stop a direction only when false, already known, or clearly disproportionate; preserve the obstruction/counterexample.
