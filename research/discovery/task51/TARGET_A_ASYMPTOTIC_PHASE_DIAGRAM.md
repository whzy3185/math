# Target A Asymptotic Phase Diagram

The charge minimax comparison now points to

```text
m_(8k)^2       -> eta,
m_(8k+2)^2     -> c6,
m_(8k+4)^2     -> c6,
m_(8k+6)^2     -> c6,
```

using respectively the period-eight phase, one G6, two separated G6, and three
separated G6.  The residue-six candidate changes from G10 to three G6.  At
`n=510`, three G6 gives `7.905369311653343`, whereas G10 tends to
`7.977104370400546...`.

This is a candidate phase diagram, not a theorem about `m_n`: all entries are
explicit-family upper bounds except the already proved period-eight bulk
constant.  Global lower bounds require arbitrary-period crystallization (or a
replacement), charge-complete multi-slip lower bounds, and eigenvalue counting
for mixed charges.
