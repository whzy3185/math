# Controlled Citation Chain

Only links that affect problem positioning, proof architecture, or novelty
are retained.

~~~
Bilu--Linial (2006)
  -> signings as new eigenvalues of 2-lifts
  -> MSS (2015): bipartite case converts one-sided control to two-sided control
  -> Belardo--Cioaba--Koolen--Wang (2018): fixed-graph signature
     minimization is posed explicitly
  -> Suvagiya (2026 preprint): the C_n(1,2) conjecture and twisted benchmark
  -> present paper: all-even truth set and counterexample mechanism
~~~

~~~
Brunetti--Stanic (2022)
  -> exact spectral-radius extremizers for a published signed-graph class
  -> Ghorbani--Majidi (2024): extremal signed adjacency on complete graphs
  -> Conde--Dratman--Grippo (2026): extremal radius in a restricted bipartite
     class [screened out of the core library: maximization, not fixed C_n^2]
~~~

~~~
Korotyaev--Saburova (2017, 2023)
  -> periodic magnetic graph fibers, fluxes, and trace formulas
  -> Kuchment--Vainberg (2006): local perturbations of periodic graph
     operators and localized eigenfunctions
  -> present paper: period-eight bulk, bilateral G6 interface, and
     local-to-global finite-ring localization
~~~

~~~
Lin--Ning (2021)
  -> analytic large-order theorem plus finite closure in a JGT classification
Goedgebeur--Schaudt (2018)
  -> proof-producing exhaustive generation and completeness contracts
  -> present paper: finite exact completion after the structural tail
~~~

The 2024--2026 signed spectral-radius literature is important for positioning,
but no item in the audited set creates a direct novelty conflict with the
fixed-cycle-square classification.
