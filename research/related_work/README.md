## Direct Intellectual Chain

~~~text
Bilu--Linial -> MSS -> published fixed-graph signing problem
  -> Suvagiya's C_n(1,2) conjecture -> present all-even classification.

Periodic magnetic graph theory -> Floquet edge -> local perturbation/interface
  -> period-eight bulk and G6 phase slip -> IMS local-to-global tail.

Published signed-radius extremal classifications -> fixed-family analogue
  -> present fixed-C_n(1,2) two-sided minimization theorem.
~~~

## Library Layout

- bibliography: selected metadata.
- papers/core: direct and modern signed-spectral sources.
- papers/methods: periodic/Floquet, local-defect, and proof-completion sources.
- papers/historical: unavoidable signing origins.
- notes: architecture-oriented reading notes; S/A entries receive full notes.
- citation_graph: controlled chains rather than a keyword dump.
- reports: seed screen, venue architecture, current-reference audit, and final
  editorial conclusions.

Local PDFs are present only where a legal OA, author, institutional, or arXiv
version was actually obtained. Missing local PDFs are recorded in
bibliography/access_status.md.
