# Exact-r Phase-Slip Excitation Theorem

For each fixed `r in {1,2,3}` there are constants `L_r` and `C_r` such that
every legal ring containing `r` G6 interfaces with minimum bulk-cell
separation `L>=L_r` has exactly `r` squared eigenvalues, counted with
multiplicity, in the fixed window

```text
[c6-1/400,c6+1/400].
```

Each of these levels obeys

```text
|lambda_j-c6| <= C_r (9/25)^L.
```

Both interface orientations and both holonomies are allowed. The constants
are uniform over those finite choices. The theorem combines Task 52's
quasimode lower count with the Task 54 complementary upper count.
