# Sharp edge bounds for bipartite graphs with unique minimum domination

This is the second version of the unique-domination paper. It combines the sharp edge bounds at orders 3γ+1 and 3γ+2 in one complete analytic treatment.

For finite simple bipartite graphs without isolated vertices and with a unique minimum dominating set of size γ≥2, the maxima are γ(γ+7)/2 and ⌈γ²/2⌉+5γ. The first equality class is completely determined. For the second, the paper proves at least two nonisomorphic extremals for every even γ≥4, without claiming a full classification.

The prior counterexamples, finite source cases and unbalanced family are explicitly credited. See SOURCE_STATUS.md for the bounded source comparison and VERSION_HISTORY.md for the preserved seven-page predecessor.
