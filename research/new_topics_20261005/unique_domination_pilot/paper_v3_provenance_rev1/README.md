# Sharp boundary bounds and edit instability in uniquely dominated bipartite graphs

Version3 combines the two sharp boundary edge bounds, their complete equality classifications, and the first-boundary edge-edit stability theorem with a matching-order obstruction.

The graph class consists of finite simple bipartite graphs without isolated vertices, with a unique minimum-cardinality dominating set of size γ≥2. Connectedness is not required for the upper results. All extremal graphs and instability examples are connected.

At n=3γ+1 the maximum is γ(γ+7)/2, with one equality class. At n=3γ+2 it is ceil(γ²/2)+5γ, with3 classes at γ2,1 at odd γ≥3, and2 at even γ≥4. At the first boundary, exact edge deficit t gives unlabelled edit distance at most12γt; connected examples require orderγt edits and disprove dense asymptotic edit stability.
