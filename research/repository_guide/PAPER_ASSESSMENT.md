# 当前文章与成果整合：本轮初步评估

日期：2026-09-05。评估对象：冻结八周期稿 `6766ecb`、结尾纠错
`2dc5b90`、一般跳长证明与定量界 `29773c3`。

这是同一研究代理对现有材料的批判性阅读，不是独立专家审稿、已校准
编辑评估或接受概率预测。按用户本轮要求，没有启动新数学探索，也
没有重新进行大规模外部文献检索。本报告先给出由现有证据支持的判断。

## 1. 直说结论

八周期稿已经是一篇完整研究论文的形态，具有非平凡的精确计算、
无限反例族和首周期刚性。它不是只有搜索输出的实验报告。但是，
**我目前不赞成沿用“已达到JGT水平”“稳LAA”“只剩作者信息”这些判断。**
结尾曾与同文已证定理矛盾，证明呈现仍有可检查性问题，外部新颖性
比较也没有达到足以给出可靠期刊等级判断的程度。

纠错后的稿件可以作为下一轮严格审读的基线；“可以审读”不同于
“现在就建议投稿”。问题主要在贡献定位、全文准确性与关键证据呈现，
并不只是英文润色。

## 2. 现稿真正有价值的部分

| 长处 | 具体依据 | 对论文的价值 |
|---|---|---|
| 给出全部有限环的精确值而非仅数值上界 | §4两种holonomy和显式色散 | 读者能验证有限与无限模型之间的关系 |
| 提出“为何是八”的数学回答 | §5最小primitive period与唯一轨道 | 将一个反例提升为局部分类问题 |
| 计算前先做完整归约 | 矩不等式、合法性、二面体轨道、Rayleigh表 | 有限计算有明确数学范围 |
| 结构与可解性有同一原因 | §3半胞反对易、§4降维与中心四次式 | 论证主线基本连贯 |
| 新推广提供真正的参数族 | G4对每个偶跳长均成立，G6有统一量化界 | 有机会把八周期从特例升级为一般机制的精细实现 |

主定理强弱不按公式数、Lean行数、验证器数量或目录大小评判。最有
分量的是一般机制能解释多少数学对象、是否得到别人尚未得到的结论。

## 5. 一篇文章是否已经装不下

**整个仓库当然不应装进一篇文章；当前一般跳长主线与八周期精细特例
则尚没有必须拆成两篇的理由。** 两者共用规范、Bloch、chiral工具，
八周期又正好是新构造的`s=2`情形。仅因成果数量增加就拆分，会造成
方法、动机和背景重复。

我的初步建议是保留一条候选整合主线，下一轮审查通过后再决定：

1. 固定底图上的谱半径优化问题及真正比较基准；
2. 一般跳长的规范、奇偶性与半胞结构；
3. 全偶跳长对径构造及Chebyshev约化；
4. 全相位sub-eight证明、有效谱隙和有限图比较；
5. `s=2`的完整根式色散、首周期与该周期刚性。

这不是本轮新增写稿，也不是已经确定的投稿结构。它说明现有结果
具备一条相容的故事。一般主定理必须经过独立数学审查和前驱比对，
才能替换旧稿主定理；不能直接把研究笔记拼进TeX。

应当另外保留：

- 平坦共振分类：与经典结果重叠较强，是否放入正文取决于解释主线
  的必要性，不为展示工作量加入；
- R2/R4/R6/G6与all-even计算分类：研究问题和证明体系不同，更接近
  单独接口/分类工程，不作为本轮整合正文；
- 旧poset等分支：完全独立，不参与本论文。

## 6. 下一阶段应完成的判断，而不是继续无边界加定理

用户希望最终投稿，由研究代理负责把技术问题解释成可决策的方案。

4. 给出明确有限的修订清单和可投稿版本，而不是把所有开放猜想变成
   投稿前必须解决的任务。
