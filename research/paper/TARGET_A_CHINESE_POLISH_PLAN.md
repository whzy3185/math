# Target A 中文数学期刊稿修订计划

## 冻结边界

- Math changed: **NO**
- English manuscript changed: **NO**
- 数学与英文语义基准：`manuscript_tex_pub/`
- 允许改动：中文版翻译、术语、句法、版式与前置信息。
- 禁止改动：定理、命题、引理、公式、数据、数值、证明逻辑、结论范围、标签、
  引用关系与参考文献事实。

## 计划替换

| 原表达 | 统一表达 |
|---|---|
| 带符号图、带符号循环图、带符号邻接矩阵 | 符号图、符号循环图、符号邻接矩阵 |
| 闭步、闭步字、闭步矩 | 闭游走、闭游走步长序列、闭游走矩 |
| 极小元、非极小元 | 最优相位、非最优代表元 |
| 八屏障 | 阈值 8、谱阈值 8 |
| 低周期谱前沿 | 低周期谱极值分类 |
| 孤立见证、见证 | 显式反例、显式构造、证书 |
| 记账、完备性记账 | 计数、完备性核验 |
| 生产阶数、生产检查点 | 正式计算阶数、计算检查点 |
| 完整性重放、慢速生成器审计 | 完整性复核、慢速生成器核验 |
| 展示周期、展示胞 | 表示周期、所选周期胞 |
| 平方能带、最高能带 | 谱带值的平方、最高谱带 |

## 修订顺序

1. 重建中文首页及元数据接口。
2. 统一标题、定理名称和章节名称。
3. 逐段消除直译句法与工程报告语气。
4. 运行术语审计和中英文数学结构一致性门禁。
5. 重新编译、逐页检查并交由独立中文审稿角色复核。
