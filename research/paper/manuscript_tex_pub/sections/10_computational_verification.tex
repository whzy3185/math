\section{Computer-Assisted Verification}\label{sec:computational-verification}

Several principal results combine human arguments with finite exact
computation. This section states precisely what is proved by computation, what
is proved analytically, and how the two layers interact.

\subsection{Proof classification}

The Floquet direct sum, determinant identity, sharp positivity expansion,
operator equivalences, cancellation baseline, moment barrier, conversion from
the grouped moment identities to the defect inequalities, and chiral reduction
are algebraic proofs presented in Section~\ref{sec:preliminaries} and
Sections~\ref{sec:periodic-construction}--\ref{sec:eight-barrier}.

The following assertions are finite computer-assisted theorems:

\begin{enumerate}
\item every switching class at each even order \(8\leq n\leq 30\) satisfies the conjectured bound;
\item the 2,626 legal flux/dihedral orbit representatives through displayed period 16 form a complete finite phase space;
\item the exact certificate partition used in Theorem~\ref{thm:low-period-frontier} covers every one of those representatives;
\item the coefficient collection underlying \eqref{eq:general-flux-moments}-\eqref{eq:general-excesses}, together with the stated \(F_{4}\), \(F_{6}\), and \(F_{9}\) values, consists of exact computer-assisted symbolic identities reproduced by the general-period moment checker;
\item the closed-walk first-positive indices and five residual Rayleigh quotients are the exact outputs of integer or rational arithmetic.
\end{enumerate}

Independent re-execution and independently written checkers strengthen
confidence but are not additional hypotheses of the theorems.

\subsection{Exactness of finite decisions}

Floating-point eigenvalues are used only to locate likely maximizing fibers or
to propose small rational vectors. A finite decision enters the proof only
through one of the following exact forms:

\begin{itemize}
\item a rational Rayleigh inequality computed from an integer matrix and integer vector;
\item a positive-definiteness certificate from fraction-free or rational elimination;
\item a Sturm root-isolation certificate for an integer polynomial;
\item an exact integer closed-walk excess;
\item an exact orbit count and orbit-size sum.
\end{itemize}

Thus no strict theorem inequality depends on a floating tolerance.

\subsection{Minimality computation}

At \(n=8,\ldots,20\), direct enumeration covers all \(2^{n+1}\) switching classes.
At \(n=22,\ldots,30\), the computation enumerates canonical quadrilateral-flux
bracelets, retains both holonomies, and attaches the exact dihedral orbit
multiplicity. The represented switching-class total is checked against
\(2^{n+1}\). The largest order therefore represents 2,147,483,648 switching
classes by 17,929,600 canonical spectral states; it does not run 2.147 billion
independent test cases.

For each large order \(n=24,26,28,30\), the canonical \(Q\)-representative set
has also been compared record by record with an independently written C
scanner. The production route is a fixed-weight FKM necklace recursion, in the
tradition of canonical necklace and bracelet generation
\cite{FredricksenMaiorana1978,Sawada2001}. The independent route instead scans
all \(2^n\) binary words, filters parity, constructs every dihedral image
directly, and marks complete orbits in a bitmap. It shares neither traversal
nor canonicalization code with the production generator. Exact destructive
set consumption verifies the canonical word and orbit size of every record;
the comparison does not infer set equality from a common digest or from equal
cardinality.

The regenerated ordered input digests, ordered certificate digests, shell
counts, represented totals, and terminal checkpoint chains agree with the
original computations; the mathematical mismatch count is zero. Integrity
replay of committed checkpoints is distinguished from this regeneration: it
authenticates stored execution records but does not recreate every per-state
inequality.

The independent representative counts are 176,906, 649,532, 2,405,236, and
8,964,800 at orders 24, 26, 28, and 30, respectively. At each order the missing,
duplicate, unconsumed, and orbit-size-mismatch counts are all zero. Summing the
independently reconstructed orbit sizes gives \(2^{n-1}\) legal \(Q\) words;
adjoining the two holonomies and two global-sign lifts gives all \(2^{n+1}\)
switching classes. This is a coverage certificate, separate from the exact
spectral certificate attached to each production state.

A second full decision route closes that separation at the large orders. The C
scanner emits its independently reconstructed canonical records in increasing
integer order. A standalone Python checker, which imports none of the
production signing, matrix, threshold, or certificate routines, reconstructs
both Hamilton holonomies from each record, builds the signed adjacency matrix,
and proposes an integer vector from a floating eigensolver. It then evaluates
\(\lVert Av\rVert^2/\lVert v\rVert^2\) with integer arithmetic and compares it
with a certified rational upper endpoint for \(\rho_-(n)^2\). The distinguished
state is checked by exact characteristic-polynomial divisibility. At
\(n=24,26,28,30\), respectively, this route decides 353,812, 1,299,064,
4,810,472, and 17,929,600 spectral states, with one exact optimizer and no
uncertified nonoptimizer. Thus the strengthened result does not rely solely on
repeating the production certificate digest.

\subsection{Low-period computation}

For each \(1\leq p\leq 16\), one route explicitly partitions all legal flux words into
dihedral orbits. A second route uses Burnside's lemma and permutation-cycle
parities. The representative set, not merely its cardinality, is compared with
an independently generated canonical set; deterministic orbit identifiers are
bound to lexicographic order. Each stored row is then checked for legal parity,
canonicality, orbit size, \(\tau\) lift, primitive periods, operator equivalences,
and an exact certificate.

The resulting 2,626-row table has no missing or duplicate canonical
representative. The exact exclusion partition \eqref{eq:frontier-partition} has no overlap and no
unresolved row.

Together they bind

requirements, order-24 through order-30 checkpoint chains, regeneration

the committed production checkpoints provide per-chunk integrity replay at

artifact through order 22 is an aggregate attestation, not a substitute for
that regeneration.

The reference environment is Python 3.12.13 with NumPy 2.3.5, SymPy 1.14.0,
and pytest 9.1.1. A machine-readable requirements file pins the Python
packages. The default suite and the three explicitly enabled slow generator
audits can therefore be run from a clean Python 3.12 environment using
repository-relative commands listed in Appendix~\ref{app:computational-protocol}.

Two residual trust boundaries remain and are disclosed rather than hidden, as
is standard practice for large proofs by exhaustion~\cite{Lam1991}. First, the
two enumeration routes necessarily implement the same proved mathematical
quotient \((Q,\alpha)/D_n\), although they do so with different algorithms,
languages, and data structures. Second, the repository does not archive every
large-order integer Rayleigh vector as a separate file. The production and
independent decision routes recreate those vectors and verify their
inequalities, while separate ordered digests and checkpoint chains bind each
run. For orders through 22, the compact historical artifacts likewise
authenticate aggregate records rather than one independently replayable file
per state. These are execution-trust limits, not floating-point tolerances or
unverified orbit counts.
