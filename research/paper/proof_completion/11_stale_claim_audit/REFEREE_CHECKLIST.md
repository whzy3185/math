- [x] The scan covers tracked text/code and includes both formal manuscripts.
- [x] Search terms include rank-one, exact-`r`, codimension-`r`, `I_r`, and
  `r x r` variants.
- [x] Every relevant file and line is classified in the canonical table.
- [x] Combinatorial phrases such as "exactly `r` gaps" are not mislabeled as
  spectral errors.
- [x] Weak but true "at least `r`" statements are distinguished from false
  exact-`r` statements.
- [x] Historical files are retained and not silently rewritten.
- [x] Retraction scripts and tamper strings are marked safe archive material.
- [x] Two source-use hazards are explicitly barred from manuscript import.
- [x] The canonical dimension is two at one G6 and `2r` for separated rings.
- [x] No reduced-symmetry `r x r` theorem is asserted without proof.
