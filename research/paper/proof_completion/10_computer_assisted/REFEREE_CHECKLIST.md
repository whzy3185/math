# Referee Checklist: Computer-Assisted Proofs

- [x] Every theorem names its finite object before naming a script.
- [x] Every exhaustive claim includes a soundness and completeness bridge.
- [x] Every strict spectral endpoint is exact rational, algebraic, interval,
  or full-matrix LDL/Bareiss.
- [x] Floating point is limited to discovery and witness proposal.
- [x] Hashes are described as provenance, not proof.
- [x] Checker independence is stated by mechanism.
- [x] Shared helper code is disclosed where present.
- [x] Tamper tests are listed for fail-closed certificate families.
- [x] Historical false exact-`r` fields are rejected by current checkers.
- [x] The period frontier is bounded by `p<=24`.
- [x] Exact read-only and high-precision evidence are excluded from the
  theorem table or explicitly labeled non-theorem.
- [x] The minimal reproduction does not require a GPU, network access, or a
  rerun of the entire discovery history.
