\subsection{One-command verification}

From the root of a clean checkout, the identified package is verified by
\ifdefined\TargetAAnonymous
the single entry point documented in its blinded archive.
\else
\begin{verbatim}
python3 research/scripts/verify_target_a_submission.py --full
\end{verbatim}
\fi
The entry point first audits the manuscript, bibliography, anonymity,
certificate manifest, digests, and frozen historical source trees. It then
runs all proof-grade verifiers and the focused tamper-test suites. The exact
tasks are CPU-only; no GPU library is required. Python 3.11 or later and
\(8\) GiB of memory suffice, with \(16\) GiB recommended for comfortable
parallel use. The measured reference runtime for the final checkpoint is
recorded in the Task 59 handoff rather than hard-coded into this document.

\subsection{Scope}

The separated-interface theorem is restricted to
\(r\in\{1,2,3\}\) and \(D\geq1040\). It counts eigenvalues with multiplicity
and proves neither individual simplicity nor a sign for the leading
interaction. The single-gap theorem concerns positive single gaps only.
Neither result classifies arbitrary multi-interface minimizers.
