# Target A 中文数学期刊通用投稿母版

本目录是 `manuscript_tex_pub/` Generic 稿件的中文翻译版。章节顺序、定理与
证明环境、公式、标签、交叉引用、表格、代码清单和参考文献元数据均与英文版
保持一致；只翻译面向读者的正文和结构名称。英文 publication manuscript 是
本次大修的主稿，冻结 V2 仍提供不变的定理与证明核心；本目录不替代英文投稿
稿件。

该版本采用中文数学核心期刊常见的通用稿件结构，不代表“北大核心统一模板”。
最终投稿仍须按目标期刊的官方模板、栏目要求和参考文献格式进行适配。

默认入口为 `main.tex`。如需显示冻结英文稿的题名、摘要和关键词接口，可在
编译前定义 `\IncludeEnglishAbstract`；书眉字段由 `\TargetARunningTitle`
保留，通用构建暂不显示。
