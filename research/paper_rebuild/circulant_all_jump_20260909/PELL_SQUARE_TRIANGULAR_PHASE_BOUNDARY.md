# Pell and square-triangular structure of the exact phase boundary

Date: 2026-09-10

Status: **Proved**. This is an arithmetic corollary of the exact general-separation phase diagram.

## 1. Spectral threshold sequence

The exact phase diagram is

\[
R_{N,m,q}<8
\quad\Longleftrightarrow\quad
2m<T_N(3).
\]

Since `T_N(3)` is odd, the largest safe defect parameter for a fixed complementary bulk length `N` is

\[
\boxed{
M_N:=\frac{T_N(3)-1}{2}.
}
\tag{1.1}
\]

The first values are

\[
\boxed{
M_1,M_2,M_3,M_4,M_5,M_6,\ldots
=1,8,49,288,1681,9800,\ldots
}
\tag{1.2}
\]

## Theorem A — square-triangular phase boundary

For every `N>=1`,

\[
\boxed{
\frac{M_N(M_N+1)}2
=U_{N-1}(3)^2.
}
\tag{1.3}
\]

Thus the triangular number with index `M_N` is a perfect square. In particular, the spectral phase boundary is exactly the classical square-triangular index sequence.

### Proof

The Chebyshev identity

\[
T_N(x)^2-(x^2-1)U_{N-1}(x)^2=1
\]

at `x=3` gives

\[
T_N(3)^2-8U_{N-1}(3)^2=1.
\tag{1.4}
\]

Since

\[
T_N(3)=2M_N+1,
\]

substitution into (1.4) yields

\[
(2M_N+1)^2-8U_{N-1}(3)^2=1.
\]

After expansion and division by eight,

\[
\frac{M_N(M_N+1)}2
=U_{N-1}(3)^2.
\]

This proves (1.3).

## 2. Pell parametrization

Put

\[
X_N:=2M_N+1=T_N(3),
\qquad
Y_N:=U_{N-1}(3).
\]

Then

\[
\boxed{X_N^2-8Y_N^2=1.}
\tag{2.1}
\]

Moreover the closed forms for Chebyshev polynomials give

\[
\boxed{
X_N+\sqrt8\,Y_N
=(3+\sqrt8)^N
=(3+2\sqrt2)^N.
}
\tag{2.2}
\]

Hence `(X_N,Y_N)` is the `N`th positive Pell solution generated by the fundamental unit `3+sqrt(8)`.

Conversely, every positive solution of

\[
X^2-8Y^2=1
\]

is generated by a positive power of `3+sqrt(8)`, and therefore appears in (2.2). Thus the threshold sequence exhausts the positive square-triangular indices.

## 3. Recurrence for the exact safe threshold

The Chebyshev recurrence

\[
T_{N+1}(3)=6T_N(3)-T_{N-1}(3)
\]

implies

\[
\boxed{
M_{N+1}=6M_N-M_{N-1}+2,
}
\tag{3.1}
\]

with

\[
M_1=1,
\qquad M_2=8.
\]

Equivalently, after shifting

\[
\widetilde M_N:=2M_N+1,
\]

one has the homogeneous recurrence

\[
\widetilde M_{N+1}=6\widetilde M_N-\widetilde M_{N-1}.
\]

Thus the exact largest safe defect length can be computed without any spectral calculation once `N` is known.

## 4. Spectral interpretation

The all-parameter theorem can now be written in the integer form

\[
\boxed{
R_{N,m,q}<8
\quad\Longleftrightarrow\quad
m\le M_N.
}
\tag{4.1}
\]

where `M_N` is the square-triangular index sequence (1.2).

The next integer

\[
m=M_N+1
\]

already produces a super-eight antiperiodic fiber. Hence the Pell sequence is not a numerical approximation to the phase boundary: it is the exact finite spectral transition.
