# 通用数学论文流程

这是从研究问题到投稿前真人决定的完整流程，包含十六个阶段、八种角色提示词、八份 JSON Schema，以及可执行的台账和输入包检查工具。

这个公开包只含通用方法、软件、模板、合成示例和公开政策资料。它不含真实论文、研究项目标识、私人文件路径、论文哈希、真实评审记录或授权凭据。

## 运行

```sh
python3 scripts/validate_bundle.py
python3 examples/odd_sum_check.py
python3 scripts/make_synthetic_example.py /tmp/generic_math_example
python3 scripts/workflow_check.py readiness /tmp/generic_math_example/record.json
```

合成示例中的作者、评审和授权都是虚构测试数据。结构检查通过，不会让这些数据变成真实证明或真实同意。

## 主线

目标政策 → 问题与前人工作 → 主张证据台账 → 证明义务 → 反例与精确实验 → 摘要引言 → 证明结构和记号 → 图表 → 独立数学审计 → 新上下文盲评 → 不同编辑修订 → 复审 → 形式化覆盖 → PDF 检查 → 固定版本补充材料 → 真人决定

完整的输入、输出、负责人、通过条件、修复和停止规则在 `WORKFLOW.md`。每个评审上下文最多两轮；旧状态暴露要如实记录，不能靠“忘记”恢复盲评。

有限精确检查和无限范围的解析证明必须分开。编译、哈希、程序一致或没有搜到前人结果，都不能替代对应的数学论证。真实作者同意、期刊政策适配和发布权限也不能由校验器生成。

把真实项目材料放在单独获准使用的本地目录，显式传入检查工具。不要将其标识、路径、哈希或运行记录补入这个公开包。公开范围见 `MINIMIZATION.md`。
