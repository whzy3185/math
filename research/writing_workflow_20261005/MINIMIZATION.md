# Public package minimization

The public payload is limited to reusable methodology, generic software, schemas, prompts, templates, synthetic fixtures, and public primary-source guidance.

Excluded content includes real manuscripts and proof/data files; research project names or identifiers; private source paths; manuscript hashes or sizes; real reviewer/context identifiers; real review reports; real author/consent/access receipts; and manifests that indirectly inventory such material. Renaming, encoding or moving excluded metadata does not make it publishable.

Every shipped fixture is explicitly synthetic. The elementary arithmetic demonstration is provided for teaching the evidence distinction, with no novelty or formal-verification claim. Any manifest in this package inventories only the generic public files themselves.

The candidate is assembled into a new directory without changing prior local archives. It is scanned against a private identifier/path/hash corpus and inspected file by file. The sensitive comparison corpus and detailed private findings are never included in the public payload. An independent packaging/privacy check is required before any authorized publication.

Use explicit file allowlists and verify each listed digest. Do not append separately supplied project inputs or their generated reports to this distribution. Publication must use a separately authorized clean revision history; successful local validation does not authorize uploading any material.
