# Supplement Boundary Plan

## Keep in the main paper

1. Exact definitions of the signing, switching coordinates, twisted benchmark, reference bulk, and sector charge.
2. Statements and proof strategy for the period-eight bulk and G6 mechanism.
3. The G6 root isolation interval and the fact that the proof uses an exact transfer/Evans certificate; not every coefficient expansion.
4. The finite-cycle construction and the complete discrete IMS estimate with the constants needed for `n>=240`.
5. The mathematical finite-reduction theorem: coverage, pruning soundness, cyclic closure, and terminal-certificate semantics.
6. One representative LDL failure certificate and one representative equality terminal certificate.
7. The final disjoint order partition and all-even classification theorem.

## Move to the supplement

1. Full period-eight fiber coefficient expansions, Sturm chains, and all rational interval tables.
2. Defect transfer matrices, cofactor vectors/charts, resultants, and symbolic elimination outputs.
3. Full 96-row finite failure manifest, raw signing words, LDL pivot lists, hashes, and checker commands.
4. Local-window databases, de Bruijn state tables, parity-lift terminal lists, and all terminal Rayleigh vectors.
5. Exact-`2r` cluster/Feshbach results, bounded multi-gap exploration, and other correct but nonessential strengthening.
6. Reproducibility environment, artifact digests, and test commands.

## Exclude from a submission proof package

1. Read-only period-25/26 frontier scans.
2. High-precision interaction tables without interval-certified theorem status.
3. Obsolete rank-one/exact-`r` formulations, except a brief correction note if needed to avoid ambiguity.
4. Discovery chronology and search history.

The supplement is evidence-bearing, not a dumping ground: every included raw
artifact must bind to a main-text theorem or a clearly labeled optional
result.
