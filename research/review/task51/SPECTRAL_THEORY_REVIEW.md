# Spectral Theory Review

The exact neutral-core inertia is useful, but it also exposes the main flaw in
a naive Birman-Schwinger argument: a charged interface changes bulk sector and
is not compact relative to one fixed gauge.  Any spectral-counting theorem
must use piecewise bulk comparison.  The three-G6/G10 numerical margin is
large and credible as an upper-bound reframe; it is not a minimizer theorem.

Verdict: prioritize fixed-r interface counting and a high-precision effective
Evans matrix.  Do not claim pairwise interaction from below-resolution data.
