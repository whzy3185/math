## 版本与使用边界

- 阅读原协议、初版复核表和独立v2同时保留；v2是独立增补建议，没有替换原版。验收题中的原空白仍为空白，未变成已作答
- 最新安全会议筛选仍只有PETS/PoPETs 2027明确通过“不线下到场仍能发表”；远程注册或报告细则仍待核。DSN、SACMAT的预期现场出席措辞保留为UNKNOWN/待核，未改成明确禁止远程
- 费用、截止日和公开状态只代表所标日期与届次；UNKNOWN、未公布、未核实均没有换算成0或已满足
- “90_历史材料”是原批次完整细证据。旧排序、旧条件或旧稿评价不会自动覆盖最新整合版；前两批会议尤其不能当作已经通过远程硬条件的候选
- 期刊条款、样本做法、编辑判断和数学证明审定保持区分；本次转换没有新增研究结论或证明，也没有修改论文
